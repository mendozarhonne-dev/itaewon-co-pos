ITAWEON & CO. CUSTOMER LOYALTY PORTAL — FIRESTORE RULES ADD-ON

The customer portal now uses Firebase Email/Password accounts (free on Firebase Spark). Staff must enter the customer's email when creating the loyalty card. Customers must verify that email before they can read the card.

IMPORTANT:
1. Open Firebase Console → itaewon-co-pos → Firestore Database → Rules.
2. Keep all existing POS rules and helper functions intact.
3. Add/replace only the public_loyalty_cards match block shown below.
4. Publish the rules, then test with a customer account whose verified email exactly matches the email entered on that customer's POS loyalty card.
5. The POS sync must have run after the code update so each public card contains accountEmail.

Inside match /databases/{database}/documents, use this block:

  match /public_loyalty_cards/{customerId} {
    // Only the verified email linked by staff to this card can read it.
    allow get, list: if request.auth != null
      && request.auth.token.email is string
      && request.auth.token.email_verified == true
      && resource.data.accountEmail == request.auth.token.email;

    // Staff POS accounts maintain the safe customer-facing card summary.
    allow create, update, delete: if isItaewonPosStaff();
  }

Keep the helper function from your existing rules file:

function isItaewonPosStaff() {
  return request.auth != null && (
    request.auth.token.email == 'mendoza.rhonne@gmail.com' ||
    (
      request.auth.token.email is string &&
      exists(/databases/$(database)/documents/pos_users/$(request.auth.token.email)) &&
      get(/databases/$(database)/documents/pos_users/$(request.auth.token.email)).data.active == true &&
      get(/databases/$(database)/documents/pos_users/$(request.auth.token.email)).data.role in ['cashier', 'manager']
    )
  );
}

Security notes:
- The portal reads only public_loyalty_cards, never private POS sales, products, staff, or config.
- Do not grant customers read access to pos_loyaltyCustomers or pos_config.
- Existing cards need an email added by staff in the POS, then use “Sync digital customer cards”.
- If a card was already created before this update, edit that member's account email in POS or create an email-link editing feature before expecting portal access.
